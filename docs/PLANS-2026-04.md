# Plans — April 2026

Outstanding items from prior planning docs, plus new ideas.

---

## 1. Security

### 1.1 Password hashing

Passwords are still compared as plain text in `auth.py`. Replace with bcrypt or argon2. Remove or wire up the unused `auth_hash_sfll` config field.

### 1.2 Camera credentials visible in process list

`streaming.py` builds `rtsp://user:pass@host` and passes it as a command-line argument to FFmpeg, visible via `ps aux`. Use FFmpeg's `-headers` option or pipe credentials via environment variable.

### 1.3 Cookie missing `Secure` flag

`auth.py` `set_cookie()` doesn't set `secure=True`. Add it for production (behind HTTPS).

### 1.4 CSRF allows missing Origin/Referer

`csrf.py` passes requests through when neither header is present. Consider rejecting POST requests with no Origin/Referer.

### 1.5 Exception details leaked to client

`routes.py` still has `raise HTTPException(detail=str(e))` in cancel/remove routes. Log full traceback server-side, return generic message to client.

## 3. Reliability

### 3.1 No graceful FFmpeg shutdown on app exit

`signal_shutdown()` breaks SSE loops but does not terminate running FFmpeg subprocesses. Track child PIDs and SIGTERM them on shutdown.

### 3.2 Silent `ALTER TABLE` migration failure

`database.py` catches all exceptions with bare `pass` during migration. Log the exception or use proper column-existence checks.

---

## 4. Code Quality

### 4.1 Database session boilerplate

Every function in `database.py` manually opens/closes sessions with try/finally. Refactor to a context manager or FastAPI `Depends(get_db)` pattern.

### ~~4.2 Duplicate time-zone and formatting logic~~ DONE

### 4.3 f-string logging

Logging throughout the codebase uses f-strings (`logging.info(f"...")`), which evaluate even when the log level is disabled. Use lazy formatting (`logging.info("msg %s", val)`).

### 4.4 Mixed route registration styles

`main.py` mixes `@app.get` decorators with `app.post("/path")(handler)`. Pick one style.

---

## 5. UX

### 5.1 Confirmation before destructive actions

Cancel-stream and remove-job buttons fire immediately. Add an inline confirmation step.

### 5.2 Field image staleness indicator

Show the snapshot's age ("Last updated X minutes ago") and highlight if stale.

### 5.3 Empty state messaging

When no streams are scheduled, show a helpful message orienting new users.

### 5.4 Mobile card layout

Consider a card layout on mobile breakpoints instead of the stream table.

---

## 6. Infrastructure

### 6.1 Health check endpoint

Add a `/health` endpoint for Docker/orchestrator health checks.

### 6.2 CDN vs local assets

`base_shell.html.j2` loads Bootstrap and Datastar from CDN, but local copies exist in `static/`. Pick one approach — local-only for offline field deployments seems right.

### 6.3 Docker Compose static mount

`docker-compose.yml` mounts the entire `static/` directory, overriding container-baked assets. Mount only the specific files needed (e.g., `field.jpg`).

### 6.4 Log rotation

FFmpeg log files in `logs/` have no rotation or cleanup. Add a periodic cleanup job.
